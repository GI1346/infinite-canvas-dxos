# BlinkFlow Windows 桌面版

BlinkFlow 保留开源画布的多维表格、并发生成和自定义中转协议，新增 LLM 多模态分析、本地图片编辑与 Ctrl 扫线断开连线。应用名称、首页、favicon 和 Windows 图标使用 BlinkFlow；图标采用用户提供的原图。

## 下载与升级

从 [本仓库 Releases](https://github.com/GI1346/infinite-canvas-dxos/releases) 下载实际已发布的 `BlinkFlow-Setup-<版本>-x64.exe`。本轮工作版本为 `0.20.7`，包含图片预览、离屏生成、滚轮灵敏度、真实像素、桌面批量下载、auto 比例与分辨率独立传递及平移性能优化。源码和安装包已发布到 [v0.20.7 Release](https://github.com/GI1346/infinite-canvas-dxos/releases/tag/v0.20.7)，远端安装包与源码 ZIP 的 SHA256 已与本地核对一致；校验值见 `SHA256SUMS-0.20.7.txt`。

应用 ID、稳定本机地址 `http://127.0.0.1:17456` 和数据键保持不变。新版桌面存储代码将数据统一置于**安装时选择的程序目录**下的 `BlinkFlowData`，不是下载的安装包所在目录。首次启动复制并逐文件校验旧 `%APPDATA%/Infinite Canvas DXOS` 桌面数据；完成标记写入后不再重复迁移。原目录不删除，也不提供清理旧目录按钮。请先退出旧版再启动新版。纯浏览器版的数据不会自动转入桌面版。

「配置 → 本地存储」显示程序目录和数据完整路径，可打开目录。`Profile` 保存画布、图片、素材、API 配置、协议、历史和浏览器缓存，`Temp` / `Logs` / `CrashDumps` / `Downloads` 保存临时文件、日志、崩溃文件和应用下载。安装目录必须可写；失败会明确报错，不会悄悄回退 AppData。外部原文件、其他进程（如单独启动的 Agent / 代理）的数据和 Windows 自身文件不在应用管理范围内。

「清除其他数据，保留 API 配置」经确认后卸载页面并重启，在 Chromium 打开数据库前清除应用数据目录，保留渠道 URL、各自独立 Key、模型与协议绑定、自定义协议及 Agent 连接凭据，再恢复后启动。无备份；画布、素材、图片、历史、日志、缓存、临时文件、应用下载、其他偏好和 WebDAV 配置会清除。失败保留 API 恢复记录，下次启动继续恢复；该记录不包含在源码或安装包。安装器不会删除 `BlinkFlowData`。发布核对成功后本地只保留 **1 份最新版安装包**；源码继续保留。

## 中转站与独立密钥

在「配置 → 渠道」分别填写并保存：

| 渠道 | 模型列表 / API 地址 | 密钥 |
| --- | --- | --- |
| 65535 绘画（独立密钥） | `https://sub-proxy-us.65535.space` | 生图专用 Key |
| 65535 对话（独立密钥） | `https://api2-cn.65535.space` | 对话专用 Key |

默认 Key 均为空，两把 Key 不混用、不随源码或安装包分发。各渠道用自己的 Key 获取模型列表及调用模型。生图异步任务地址为 `https://task-api-1-cn.65535.space`，提交、查询和续查都使用原生图 Key。

旧内置绘画渠道的默认标签会更新为「65535 绘画（独立密钥）」；仅匹配旧内置标签，不覆盖用户自定义名称、地址、Key、模型或协议绑定。

自定义协议入口为「配置 → 协议中心」，格式为开源画布 `canvas-call/v1`，不是 DXOS `dx-protocol/v2`。重命名只改名称，保留 ID、脚本与绑定；保存协议可同步保存 JSON 修改。已绑定渠道或模型的协议须先解除绑定才能删除。渠道可选真实协议名称或「65535 原生异步任务」，模型独立绑定 / 调用脚本优先。

## 画布操作

- 底部工具栏 / 空白右键可添加「多维表格」「并发生成」「LLM 多模态分析」。图片组、文本按独立输入通道进入表格，逐行或共享配对，再连接并发生成。
- LLM 节点选择文本平台、模型与提示词；换平台后必须重新选模型，缺失平台 / 模型不改用其他渠道。「文本」另存文本节点；「列表」严格解析统一表格 JSON，保留各图片来源组的独立输入列，文字列可编辑。按模型返回的行数创建任务，不因图片组更长而增加空行。运行中的 LLM 和并发节点移出视口后保持挂载，不因离屏裁剪中止本机请求；主动停止、删除或实际卸载后不接收迟到结果，再运行另存新输出。
- 表格、并发和 LLM 节点支持从正文空白区域拖动，不再只能拖左上角；浏览器三类节点实测通过。输入 2 / 3 / 4 / 5 的落点对应各自端口，保留到保存和重载。表单编辑、选择、滚动与文本选择保留。
- 按住 Ctrl 后用左键划过连线可扫线断开，并显示切线动画；一次手势作为一次撤销 / 重做。真实 React DOM 全链路自动化 15 / 15 通过；浏览器控制接口不支持按住 Ctrl 的拖动，未把该物理手势记作浏览器实测。
- 空白右键一次打开节点选择，空白双击不创建；保留节点双击编辑 / 预览和名称双击重命名。
- 左键框选、空格 + 左键平移、滚轮围绕鼠标缩放，悬停节点也有效。快捷键面板新增滚轮灵敏度 1–100（默认 50），保存后重开仍保留。按住空格不反复激活焦点按钮；编辑文本仍可输入空格。连续缩放采用最新视口并取消旧聚焦动画；平移使用 compositor 变换和量化 overscan，减少整页逐帧 React 更新。
- 节点名称常显；下载使用节点重命名后的名称，多图加序号，按真实 MIME 补扩展名，避免重复后缀。图片信息显示实际源图像素，不以节点显示尺寸冒充图片分辨率；预览内滚轮围绕鼠标位置缩放、左键拖动图片，不移动背景画布。
- Alt 拖动复制：按住 Alt 拖动单节点、多选或分组，会复制相应节点及组后代；所有关联连线（内部、外部输入、外部输出）保留，属于复制范围的端点与组归属映射到副本，范围外端点保留，原节点不动。副本不继承正在运行的任务；helper 12 / 12、实际 Project AST handler 的 React DOM 验收 11 / 11 通过，未声称物理 Alt 拖动已在浏览器实测。
- 批量下载：框选后使用多选工具栏的「批量下载」，或在分组工具栏使用同名入口；递归收集子组、去重节点，保留成功多图、重命名名称及实际 MIME 扩展名。桌面版先选择保存目录后保存独立图片，取消不写入任何文件，已有同名文件加后缀、不覆盖，也不回退默认目录。浏览器支持目录选择时保存独立图片，否则保留 ZIP 下载路径。缺图 / 读取失败跳过并提示数量，全空不输出；原图与 API 配置不变。当前桌面 IPC 隔离验收通过，原生目录选择弹窗实际点击尚未验收。
- 并发节点保留模型、比例、分辨率、质量、并发数、起始行、独立选行、停止与重试；已移除重复的尺寸输入。auto 比例与 2K / 4K 分辨率独立保存和传递，不因自动比例丢失分辨率选择；远端最终输出尺寸以实际结果为准。
- 图片上方固定显示「画笔」「裁剪 / 扩图」「多宫格裁剪」，均本地处理，不调用 AI。画笔可绘制、箭头、序号、矩形、圆形并撤销重做；裁剪框可向外扩展并填透明 / 指定色；宫格可调整切线、选择输出切片。结果另存连线新节点，原图不变。这不同于原有蓝色蒙版的 AI 局部重绘。
- 「宫格布局」按列数和间距排列选中节点，不拼图；保留比例、连线及嵌套组全部后代的偏移。
- 图像 / 视频设置浮层不触发背景框选，主题为「纯白」与「暖色」。

## 原生异步生图

提交 `/v1/tasks` 保存任务 ID，区分 `pending/running/done/failed`；未知状态继续查询。通常每 3 秒轮询，429 指数退避，沿用 10 分钟超时。超时 / 停止本机等待不等于远端任务取消；从「异步任务」用原生图渠道续查，不重复提交取结果。不混用原生和 APIMart 字段。

## 直接清理

右上角「清理」可清当前 / 全部画布的输入图片、输出图片、历史和日志；直接执行，不生成 ZIP 备份。保留 API 地址、独立 Key、渠道、协议、模型选择、表格文字和连线。默认不删素材，被其他画布、保留素材、未选日志引用的图片不删。选中日志同时清 `relay_tasks`，仅清日志不删图片文件。清理不删除电脑原图或外部中转站、Agent、WebDAV 记录。

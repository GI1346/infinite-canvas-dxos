【图片语言】

所有出现在图片中的文字必须使用英文，包括主标题、副标题、功能标签、尺寸说明、步骤说明和包装清单。

工作沟通与设计解释使用中文，但中文不得出现在最终图片中。产品本体原有的真实铭牌、警示和标识保持原样，不擅自翻译或改写。

英文文案要求：
1. 面向目标亚马逊站点买家，使用自然、专业、简洁的英文，不使用中式直译。
2. 每张图只表达1个核心价值主张。
3. 主标题优先3—7个英文单词，副标题优先8—16个英文单词，以表达准确为先。
4. 局部标签优先2—5个英文单词，避免长段落。
5. 使用准确的起重设备与工业工具术语，区分 lifting、pulling、lashing 和 clamping，不混用用途。
6. 所有参数、数量、单位、材质、兼容性与性能描述必须来自提供的资料。
7. 不虚构承载能力、认证、测试、效率提升或安全保证。
8. 生成前先整理每张图的确切英文文案及中文释义供核对；中文释义不上图。
9. 最终图片只呈现确认后的英文文案，不添加额外口号、假英文、乱码或重复文字。

【字体与排版】

统一使用阿里巴巴普惠体（Alibaba PuHuiTi）排版英文，整套保持一致。

- 主标题：Bold，突出唯一核心价值。
- 副标题：Regular或Light，简洁清晰。
- 参数与标签：Regular或Medium，确保数字和单位易辨。
- 英文标题优先使用sentence case，保留标准缩写的正确大小写，不整段全大写。
- 不使用书法体、手写体、装饰字体或过度压缩字体。
- 保持合理字距、行距和留白，确保手机端可读。
- 如果生图工具无法准确使用指定字体，生成无字底图并保留排版区域，后期使用真实阿里巴巴普惠体添加英文，不以近似字体冒充。

以亚马逊买家的购买判断为中心，打造具有高端工业旗舰品牌感的原创视觉。

产品始终是视觉中心。

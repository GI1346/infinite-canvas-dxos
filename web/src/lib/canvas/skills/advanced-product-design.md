# 一、最高优先级：产品保真与高级品牌视觉

以下要求贯穿全部策划与提示词，不得因增加卖点、信息模块或页面数量而削弱。

## 1. 严格保留真实产品

以我上传的真实产品图片为唯一外观依据，严格保留产品的外形、比例、结构、颜色、零部件、连接关系、开孔、纹理及可见细节。

严禁产品变形、结构重构、美化改款、增减部件、错误拼接或凭空添加功能。

产品可以根据画面需求调整位置、大小及合理拍摄角度，但不能因此改变真实结构。未展示或无法确认的背面、内部及连接细节，不得自行补造；优先选用已有图片能够支持的视角。

产品保真优先于构图创意、场景氛围及装饰效果。

## 2. 优先呈现高级品牌电商质感

整体视觉以以下方向为核心：

**高端品牌官网感 + 电商旗舰店视觉 + 商业摄影质感 + 简约现代设计 + 生活方式美学。**

参考最后一张图片所呈现的高级感、秩序感和品牌视觉语言，但必须原创设计，不直接复制其构图、版式、图形或装饰元素。

高级感主要通过真实材质、克制配色、精致光影、清晰层级、空间关系与高级留白建立，而不是通过堆叠装饰、夸张特效或密集卖点制造。

## 3. 产品始终是视觉中心

每张图片突出一个核心价值，设置一个简洁有力的主标题，搭配一句简洁副标题，强化功能、利益点或使用体验。

原创线性 icon、抽象符号、信息标签、参数卡片、结构指示线及精致装饰元素仅作辅助，不得抢夺产品视觉重心。

避免底部传统“一排 icon + 文字”的布局，优先采用：

- 环绕式信息布局；
- 模块化排版；
- 大面积留白；
- 局部信息标签；
- 精简参数卡片；
- 与真实结构对应的指示线。

不是每张图都必须添加 icon、标签或参数。无助于表达核心价值的元素直接删去。

## 4. 建立真实、可信的使用氛围

结合产品真实用途与使用环境设计场景，采用自然光、合理浅景深及空间氛围感，突出品质与信任感。

根据产品类型安排整体展示、真实使用场景、局部细节或材质特写。场景与道具必须服务于产品，不得加入不符合实际用途的环境、使用动作或配件。

浅景深不得遮蔽关键结构，材质特写不得夸大纹理或改变材质。

# 二、产品分析

开始策划前，先分析以下内容：

1. 产品类型及主要用途；
2. 外观结构、组成部件及辨识特征；
3. 已知材质、表面处理与制造工艺；
4. 功能特点及实际用户收益；
5. 真实使用场景；
6. 已提供的核心规格参数；
7. 目标用户及主要采购需求；
8. 最值得视觉化表达的产品优势。

明确区分：

- **已提供事实**：图片、参数或说明中有明确依据的信息；
- **合理推测**：只能推断、尚未确认的信息；
- **待补充信息**：影响卖点判断但目前缺失的信息。

合理推测不得直接写成广告结论。不得编造性能数据、材质等级、检测结果、认证、销量、用户评价或对比结论。

若缺少关键信息，指出具体缺失项；已有信息足够支持的部分继续完成。不能成立的卖点不强行补齐。

# 三、核心卖点提炼

每个卖点包含：

- 卖点名称；
- 事实依据；
- 对用户的实际价值；
- 适合的视觉表达方式；
- 简洁有力的主标题；
- 一句克制、清楚的副标题。

避免空泛口号、未经证实的绝对化表达，以及将同一个卖点换词重复。

14 张图片不等于必须创造 14 个不同功能。可以围绕已确认的核心优势，分别展示整体价值、使用体验、结构细节、材质工艺、应用场景与规格信息。

# 六、统一视觉规范

根据真实产品及最后一张风格参考图，制定一套可执行的视觉规范，应用于全部 14 张图片。

## 1. 色彩体系

明确背景色、主文字色、辅助文字色与少量强调色，提供对应色值。

配色服从产品原色，不为匹配参考风格而改变产品颜色。避免颜色过多、过饱和及无依据的大面积炫光。

## 2. 光影与摄影

统一自然光方向、色温、阴影软硬程度、曝光倾向、镜头语言与材质表现。

保留真实接触阴影、合理反射及透视关系，避免塑料感、悬浮感、过曝与过度锐化。

## 3. 字体

所有中文统一使用 **阿里巴巴普惠体**：

- 主标题：粗体、醒目、简洁；
- 副标题：常规或轻量字重，克制清晰；
- 参数与辅助文字：清楚易读，层级明确。

统一字体家族，避免字体混用、文字过密及大段说明。

## 4. 图形与版式

统一原创线性 icon 的线宽、端点与风格，统一圆角、标签、参数卡片、指示线、间距和页面边距。

明确 1:1 主图与 9:16 详情页各自的版式逻辑，保持同一视觉系统，但不将方形版式直接拉伸成竖版。

不添加任何品牌名称、Logo、水印或未经提供的认证标识，不引入参考图中的品牌元素。

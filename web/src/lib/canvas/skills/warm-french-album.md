一、总体设计方向与优先级
整体风格固定为：
暖调法式复古＋轻熟优雅＋时尚杂志编辑式排版＋生活方式商业摄影＋精致品牌画册感。
在此基础上，融合参考图片中的：
竖向长矩形照片卡片、错位叠放、精致标题组合、英文栏目标签、开放式括号、细线连接、局部下划线与少量弧线点缀。
注意区分：
- 整套统一的是文案气质、标题结构、字体层级和点缀语言。
- 不是每张使用相同文案，也不是每张复制同一构图。
- 三联竖向长矩形照片卡片的拼贴构图，仅在其中一张详情页使用。
- 其余页面沿用同一套文字与装饰系统，但根据主题采用不同布局。
设计优先级：
产品保真与信息真实＞主体突出与信息清晰＞暖调复古与统一排版＞构图变化与装饰效果。
不要为了做满14张而虚构卖点，不要为了追求画册感而弱化产品。
二、产品保真与事实约束
1. 严格参考真实产品
保留产品的：
- 外形轮廓与真实比例；
- 零部件数量及连接关系；
- 颜色、纹理与表面质感；
- 缝线、开孔、扣件、边缘等辨识细节。
严禁变形、重构、擅自改款、增减部件、混合不同款式结构。
可以调整产品位置、展示大小及有依据的拍摄角度，不得改变产品本身的结构与比例。
未提供的背面、内部、底部及隐藏结构，不得自行补造。
需要严格保真时，优先采用真实产品抠图合成、背景替换或局部编辑，不要重新生成一个外形相似但结构不同的商品。
2. 不编造产品信息
产品功能、材质、工艺、规格、配色、配置和认证必须来自已提供信息。
不能凭图片判断真皮、耐磨、防滑、透气、减震或久穿舒适等性能。
参考图片中的文案只参考表达方式，不直接照搬。其中涉及的百分比、适用范围、效果承诺等，不得迁移到本次产品。
3. 不添加品牌内容
不新增品牌名称、Logo、水印或未经提供的认证标识。
不得混入参考图中的商品、品牌、人物身份或标识。
三、固定色彩与摄影风格
1. 色彩体系
整套以暖调法式复古色系为主：
用途	色彩	参考色值
主要浅底	奶油白	#F5F0E7
辅助浅底	燕麦米	#E5D8C4

色值用于背景、文字及装饰，不用于改变商品原色。
只借鉴参考图的排版逻辑，不沿用蓝色背景、粉色强调字或冷调渐变。
通过奶油浅底、暖棕场景与少量深底交替建立节奏。避免全套发黄、发灰、过暗或厚重。
2. 摄影语言
采用柔和自然侧光、真实空间阴影、克制高光和清晰材质细节。
整体温暖，但保证：
- 白色产品不过度偏黄；
- 黑色产品不偏棕、不丢失层次；
- 金属不过曝；
- 材质不塑料化；
- 产品与地面、人物、道具之间有真实接触关系。
浅景深用于突出主体，不得模糊重要产品细节。
3. 场景语言
结合真实用途选择场景，可使用暖米色墙面、木质家具、地毯、织物与窗边空间。
道具少而准确，不机械堆满。
鞋服类产品可采用自然穿搭、坐姿、站姿、行走瞬间及局部身体取景，产品必须清楚可辨。
不直接复制参考图片中的穿搭、动作或道具组合。
4. 背景纹理
可以加入极轻微的暖白纸感或细腻织物感，增强画册质感。
纹理只在背景中若隐若现，不影响文字阅读，不覆盖商品，不制造明显旧纸污渍、折痕或粗糙噪点。
四、整套统一的文案与点缀排版系统
1. 固定文字层级
每张采用同一套信息结构：
小型栏目标签→中文主标题→一句副标题→必要的局部说明。
各层级固定，具体文字随主题改变。
小型栏目标签
设置一个与页面主题相关的简短英文栏目词，例如：
DESIGN / DETAIL / TEXTURE / SCENE / COLOR / SIZE
英文只作栏目识别，不添加无意义外文，不形成虚构品牌。
标签采用小型横向短条或轻量文字标记。主样式选定后，全套保持一致。
中文主标题
- 提炼一个清楚的核心价值；
- 原则上控制在4—10个汉字，必要时分两行；
- 不写成没有信息的空泛情绪口号；
- 可使用一组开放式角括号或细线框角辅助强调；
- 只强调一个关键词，不给整段文字添加多种效果。
副标题
- 一句说明功能、利益点、设计特点或使用关系；
- 原则上控制在12—26个汉字；
- 不堆叠多个卖点，不写大段说明；
- 不使用未经证实的绝对化承诺。
局部辅助信息
每张按需设置0—2组简短说明，可为：
- 场景名称；
- 已确认的结构特点；
- 已提供的参数；
- 颜色名称；
- 局部细节标注。
不为了保持模板而强行填充信息。
2. 固定装饰母题
全套仅使用以下一组装饰语言：
1. 开放式角括号：用于主标题外侧，笔画纤细，不做厚重边框；
2. 哑光香槟金短标签：用于英文栏目识别；
3. 细弧线或单环线：连接栏目标签与标题，作为轻量点缀；
4. 短下划线或细分隔线：强调关键词或组织局部信息。
每张都应能识别出这套语言，但不要求四种元素全部出现。
标题区保留统一识别，其他点缀随构图移动；不要每张重新发明一种装饰。
禁止彩色贴纸、荧光描边、粗箭头、复杂花纹、科技光圈及大量散落的小符号。
3. 字体规范
所有中文统一使用阿里巴巴普惠体：
- 主标题：粗体；
- 副标题：常规或轻量字重；
- 参数和辅助信息：常规字重，清晰易读。
英文栏目词采用统一的简洁字形，优先使用同字体家族的拉丁字符。
不照搬参考中的衬线中文、夸张斜体英文或大面积英文标题。通过留白、字重与对齐建立编辑感。
4. 排版位置与统一尺度
- 画面四周安全边距原则上为宽度的6%—8%；
- 标题区与摄影主体之间保留明确呼吸空间；
- 相同画幅中的标题字号、标签尺寸、线条粗细保持统一；
- 1:1与9:16分别建立字号比例，不直接拉伸套版；
- 主标题不得遮挡关键产品结构；
- 手机端查看时主次信息仍需清楚。
统一的是网格和层级，不是要求所有标题固定在同一坐标。

产品分析→核心卖点→主图方案→详情页方案→统一视觉规范→统一正面提示词→统一负面提示词→每张图AI生图提示词。

- 共5张1:1主图、9张9:16详情页；
- 每张一个明确核心价值；
- 产品结构、颜色和细节保持真实；
- 文案与参数有依据；
- 全套保持暖调法式复古，不被参考图的蓝粉配色带偏；
- 每张都有统一的文案层级与精致点缀语言；
- 只有详情页07采用三联竖向长矩形卡片；

- 产品清晰、手机端文字易读；
- 每张提示词完整、独立、可复制。
